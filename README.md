## Overview

HeronAI is a creator-focused platform built to streamline the ideation and production workflow for video content. The project presents a clean, responsive, and premium user experience that helps users plan, manage, and present their creative concepts in a highly structured and modern environment.

This repository is not just a static landing page; it is designed as a scalable frontend foundation for a future-rich video creation ecosystem. It combines a polished visual experience with modern software architecture to support the growth of a serious content and video workflow platform.

From brainstorming creative ideas to building a structured content pipeline, HeronAI aims to provide an elegant and productivity-driven digital workspace for creators, agencies, and digital storytellers.

---

## Why this project matters

The goal of HeronAI is to create a strong foundation for a next-generation creative platform where users can:

- plan and organize video ideas
- create structured content workflows
- manage creative projects in one place
- present a premium brand-first experience
- scale into a more advanced video production environment later

This makes HeronAI a compelling prototype and starting point for a real-world creator tool, portfolio platform, content workflow system, or AI-assisted video platform.

## Features

### Product and UX

- scalable architecture for expansion

## Getting started

### Prerequisites

- Node.js 18+
- npm or yarn

You can install Node.js with nvm if needed:

https://github.com/nvm-sh/nvm#installing-and-updating

### Install dependencies

```bash
git clone https://github.com/Muhammad-Ahmad-CO/heronai.git
cd heronai
npm install
```

### Run locally

```bash
npm run dev
```

Then open the local URL shown in your terminal to view the app.

---

## Available scripts

```bash
npm run dev
npm run build
npm run build:dev
npm run preview
npm run lint
npm run format
```

### Script descriptions

- `npm run dev` — starts the local development server
- `npm run build` — creates a production build
- `npm run build:dev` — creates a development build
- `npm run preview` — previews the production build locally
- `npm run lint` — runs ESLint checks
- `npm run format` — formats the project with Prettier
